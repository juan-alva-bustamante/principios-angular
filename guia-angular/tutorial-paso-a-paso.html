Fase 3 — tutorial completo, sin saltarse nada

De cero al proyecto Angular funcionando

Esta guía asume que nunca has usado una terminal ni instalado herramientas de programación. Vamos a instalar todo, crear el proyecto, y migrar cada pieza del maquetado a su componente de Angular, uno por uno, validando visualmente en el navegador después de cada paso. Instrucciones para Windows (con notas para Mac donde cambia algo importante).

Parte 1 — Instalar los programas necesarios

Vamos a instalar 3 programas. Uno a la vez, en este orden.

1.1 — Node.js

Es el programa que hace correr las herramientas de Angular.

  1. Abre tu navegador (Chrome, Edge, el que tengas) y ve a nodejs.org
  2. Vas a ver un botón grande que dice algo como "Download Node.js (LTS)" — dale clic ahí. Elige siempre la versión que diga "LTS", no la que diga "Current".
  3. Se descarga un archivo (normalmente a tu carpeta "Descargas"). Ábrelo con doble clic.
  4. Se abre un instalador: dale "Next" en cada pantalla, acepta los términos, y deja todas las opciones tal como vienen. Al final, clic en "Install" y luego "Finish".
Nota: si tu computadora te pide permiso de administrador durante la instalación, acepta (dale "Sí").

1.2 — Visual Studio Code

Es el editor donde vamos a escribir y ver el código (como un "Word" pero para programar).

  1. Ve a code.visualstudio.com
  2. Clic en el botón de descarga para tu sistema (Windows o Mac)
  3. Abre el instalador descargado
  4. En Windows, cuando llegues a la pantalla "Selecciona tareas adicionales", asegúrate de que esté marcada la casilla "Agregar a PATH" (normalmente ya viene marcada por defecto) — esto es importante, lo vamos a necesitar más adelante
  5. Termina la instalación con "Next" → "Install" → "Finish"

1.3 — Git

Es la herramienta que guarda el historial de cambios de tu proyecto y lo sube a GitHub.

  1. Ve a git-scm.com/downloads y descarga la versión para tu sistema
  2. Abre el instalador
  3. Vas a ver muchas pantallas con opciones — no cambies nada, dale "Next" a todas hasta el final (son como 10 pantallas, es normal)
  4. Al final, "Install" y "Finish"

Parte 2 — Verificar que todo quedó instalado

Vamos a abrir una terminal: una ventana donde le escribes comandos de texto a la computadora en vez de hacer clic en botones. Es la herramienta principal que vamos a usar en todo este tutorial.

Abrir la terminal (cmd) en Windows

  1. Busca el ícono de lupa 🔍 en la barra de tareas (abajo de tu pantalla), o presiona la tecla con el logo de Windows
  2. Escribe: cmd
  3. Va a aparecer una app llamada "Símbolo del sistema" — dale clic o presiona Enter
  4. Se abre una ventana con fondo negro y texto — esa es tu terminal
Si usas Mac: abre "Spotlight" (Cmd + Espacio), escribe terminal y presiona Enter.

Probar que Node, npm y Git funcionan

En la ventana de la terminal, escribe cada línea y presiona Enter después de cada una:

node -v
npm -v
git --version

Cada comando debería responder con un número de versión (algo como v20.11.0). No importa memorizar el número exacto — lo que importa es que NO diga algo como "no se reconoce como un comando interno o externo".

Si te da error: cierra la terminal, cierra la sesión de Windows (o reinicia la computadora), y vuelve a intentar el paso de "Abrir la terminal" de arriba. A veces Windows necesita reiniciar para "enterarse" de que estos programas ya existen.

Parte 3 — Instalar el Angular CLI

El Angular CLI es la herramienta que crea proyectos y componentes de Angular por ti. Se instala una sola vez por computadora.

En la misma terminal, escribe:

npm install -g @angular/cli

Presiona Enter. Va a pasar mucho texto rápido por la pantalla — es normal, tarda 1 o 2 minutos. Cuando termine, vas a ver de nuevo el cursor esperando (una línea con una ruta de carpeta y un símbolo al final, algo como C:\Users\TuNombre>).

Verifica que quedó instalado:

ng version

Debería mostrarte un pequeño dibujo hecho con texto y la versión del Angular CLI.

Parte 4 — Descargar el proyecto

Vamos a descargar (esto se llama "clonar") el repositorio que ya tiene el maquetado y esta guía, para trabajar sobre él.

  1. Elige dónde quieres guardar el proyecto. Por ejemplo, tu carpeta de Documentos. En la terminal, escribe: 
    cd Documents
    (cd significa "entra a esta carpeta". Si tu carpeta se llama "Documentos" en vez de "Documents", usa ese nombre.)
  2. Descarga el proyecto: 
    git clone https://github.com/juan-alva-bustamante/principios-angular.git
  3. Entra a la carpeta que se acaba de crear: 
    cd principios-angular
Ya tienes el repo en tu máquina si estuviste trabajando con Claude en él: si es el caso, sáltate este paso y solo asegúrate de estar, en la terminal, parado dentro de la carpeta principios-angular (usa cd para llegar ahí).

Parte 5 — Crear el proyecto Angular

Estando dentro de la carpeta principios-angular, escribe:

ng new chat-app --style=scss --routing

Puede que te haga una o dos preguntas de sí/no en la terminal (por ejemplo sobre "Server-Side Rendering"). Para todas, solo presiona Enter para aceptar la opción por defecto.

Espera 1-2 minutos mientras instala todo. Cuando termine, entra a la nueva carpeta:

cd chat-app

5.1 — Abrir el proyecto en Visual Studio Code

code .

(El punto es parte del comando — significa "abre esta carpeta donde estoy parado ahora"). Se abre Visual Studio Code con el proyecto cargado a la izquierda.

Desde ahora vamos a usar la terminal dentro de VS Code, no la ventana negra de antes. Para abrirla: menú Terminal (arriba) → New Terminal.

5.2 — Primera validación visual

En la terminal de VS Code, escribe:

ng serve

Espera a que aparezca un mensaje como Local: http://localhost:4200/. Abre tu navegador y ve a esa dirección.

✅ Validación: deberías ver una página con el texto "Hello, chat-app" y un logo de Angular. Si ves eso, el proyecto está funcionando correctamente.

Deja esa terminal abierta y corriendo — ng serve se queda "vigilando" tus archivos y recarga el navegador solo cuando guardas cambios. Para los siguientes comandos, abre una segunda terminal: clic en el ícono + que aparece junto a la terminal, en VS Code.

En el panel de archivos de VS Code (izquierda), abre src/index.html. Justo antes de la línea </head>, pega esto:

Parte 7 — Construir cada componente

Vamos a crear 5 componentes, en este orden: primero los 4 que no dependen de nadie más (chat-list, chat-header, message-thread, message-input), y al final el que los junta a todos (app-shell).

Un detalle técnico importante antes de empezar: cada componente Angular queda "envuelto" en su propia etiqueta (como <app-chat-list>). Esa etiqueta, por defecto, puede romper el diseño flexible que ya armamos en el maquetado. Por eso, en cada componente vamos a agregar esta línea al inicio de su archivo .scss: 
:host {
  display: contents;
}
Le dice al navegador "ignora esta etiqueta para efectos de diseño, compórtate como si el contenido de adentro estuviera directamente aquí". Ya está incluida en el código de abajo — no la olvides si en algún momento el diseño se ve raro.

Si tu archivo generado se ve un poco distinto (por ejemplo sin la línea standalone: true), no pasa nada — es normal entre versiones de Angular. Lo importante es que quede el import de los 4 componentes arriba, y sus nombres dentro de imports: [...].

import { AppShellComponent } from './app-shell/app-shell.component';

imports: [AppShellComponent],
